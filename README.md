# Python · заметки

Личный справочник: **14 занятий, 66 тем, 6 интерактивных разборов**. Материалы подготовлены по открытым урокам Skypro; исходные названия, номера, порядок и идентификаторы сохранены.

Сайт: **https://venchik111.github.io/python-notes/**

Краткое правило остаётся сверху. Далее сразу видны объяснение механики, самостоятельные примеры с результатами, разбор строк, сравнения и ошибки. Дополнительные нюансы раскрываются по нажатию. Объём учебных мини-конспектов увеличен примерно в 3,5 раза относительно первой версии.

## Использование

- Выбери урок слева или введи термин в поиске. Клавиша `/` переводит фокус в поиск.
- Поиск учитывает код, вывод примеров, таблицы, подписи демонстраций и скрытые пояснения. Регистр и различие `е/ё` не важны; доступны части слов и русские/английские термины.
- Нажми результат, чтобы перейти к теме. Совпадения подсвечиваются, найденные дополнительные пояснения раскрываются.
- Ссылку из адресной строки можно сохранить: она открывает конкретный урок/тему после обновления страницы. Старые ссылки продолжают работать; `&demo=1` прокручивает к интерактивному разбору.
- На телефоне список открывается кнопкой «Уроки». Escape закрывает панель; Escape в поиске очищает запрос.

Сайт работает на HTML, CSS и JavaScript без сборки. Сервер приложения, аккаунт Skypro и ключи API для его работы не нужны. Материалы загружаются с того же сайта; внешние шрифты и CDN не используются.

Пошаговые модели управляются кнопками «Назад», «Следующий шаг», «Сброс». Изменение параметров начинает пошаговый пример заново; сброс сохраняет выбранные параметры. pandas и regex пересчитываются сразу; «Назад» возвращает предыдущие настройки, «Сброс» — исходные. Автоматического воспроизведения нет. Работают клавиатура и сенсорный экран; таблицы и код прокручиваются внутри своего блока.

Это ограниченные учебные модели: произвольный Python в браузере не исполняется, реальный API не вызывается. Эталонные результаты получены с помощью Python, pandas, `re`, `unittest.mock` и временных репозиториев Git. Если модель не загрузится, текст урока, её код и ожидаемые результаты остаются доступны; кнопка «Повторить» загружает её заново.

## Локальный просмотр

Из корня проекта:

```bash
python -m http.server 8000 --directory docs
```

Открой http://localhost:8000. На macOS/Linux при необходимости используй `python3`. Открытие `index.html` через `file://` не подходит: браузер может заблокировать загрузку JSON.

## GitHub Pages

Публикация настроена в **Settings → Pages → Deploy from a branch → main → /docs**. Файл `docs/.nojekyll` отключает обработку Jekyll. После push в main GitHub повторно публикует страницу. Ресурсы имеют относительные адреса и работают под `/python-notes/`.

## Пополнение через чат

Попроси: «Обнови python-notes по новым открытым урокам Skypro». Для следующего обновления агенту нужен доступ к кабинету и репозиторию.

1. Сопоставить открытые учебные занятия с существующими идентификаторами `stream-lesson`.
2. Прочитать шпаргалку и конспект; у практик — условия учебных задач. Сохранить исходные материалы вне репозитория.
3. Объединить повторы и подготовить мини-конспекты: назначение → механика → пример с результатом → разбор строк → ошибки. Сохранить существенные параметры, ограничения и граничные случаи.
4. Добавить или обновить записи в `docs/data/lessons.json`. Не менять ID старых уроков и тем: они используются в ссылках. Самостоятельные примеры должны содержать импорты и исходные данные.
5. Обновить дату, проверить поиск/примеры/демонстрации, commit и push. При изменении числа тем обновить счётчики в README и контракт старых ссылок в `tests/topic-ids.json`; интерфейс считает темы автоматически.

Новые уроки добавляются по запросу; автоматического доступа к Skypro из опубликованного сайта нет. Рабочие выгрузки Skypro в репозиторий не входят.

## Формат данных и код

`docs/data/lessons.json`: `version: 1`, `updatedAt: YYYY-MM-DD`, список `modules`, список `lessons` в учебном порядке.

Урок: `id`, `moduleId`, `number`, `title`, `kind` (`lesson`/`practice`), `summary`, `sources`, `topics`. Необязательный `setup` содержит общие данные только для коротких примеров в начале тем.

Тема: стабильный `id`, `title`, `when`, `rule`, `code`, `language`, `error`, `details` (дополнительные нюансы), `terms` (синонимы), `references` (проверочные источники). Поле `check` задаёт проверку короткого примера: `compile`, `run` или `pytest`.

Массив `blocks` хранит видимую подробную часть:

| `type` | Поля |
| --- | --- |
| `paragraph`, `heading` | `text` |
| `example` | `language`, `code`, `check`; необязательный `output` — точный stdout |
| `list` | `title`, `items` |
| `table` | `headers`, `rows`; необязательный `title` |
| `link` | `text`, `href` — внутренняя ссылка на связанную модель |

Необязательный `demo` задаёт `type`, `title`, `intro`, `labels`, `searchText`, `language`, `code`, `output`. Код и подписи входят в поиск; `code` / `output` также служат резервом при ошибке загрузки модели. В отличие от `example.output`, это описание ожидаемого результата, а не буквальный stdout.

- `docs/app.js` — навигация, вывод материалов, безопасная подсветка и загрузка демонстраций.
- `docs/search.js` — поисковый индекс и фрагменты совпадений.
- `docs/demos/models.js` — чистые функции пошаговых моделей и выбор результатов.
- `docs/demos/widgets.js` — независимые состояния шести интерфейсов, HTML и SVG.
- `docs/data/demo-fixtures.json` — проверенные результаты подготовленных сценариев.
- `tools/build_demo_fixtures.py` — воспроизводимое получение эталонов.

Текст из данных выводится как текст, а не HTML. Состояние модели хранится в её экземпляре; перезагрузка страницы возвращает начальное состояние.

## Проверки

Для поиска, постоянства ссылок и моделей нужен Node.js; npm-пакеты не требуются:

```bash
npm test
```

Для проверки примеров и пересчёта эталонов нужны Python с `pytest`, `pandas`, `requests`, а также установленный Git:

```bash
python tests/check_examples.py
python tools/build_demo_fixtures.py --check
```

Первый скрипт компилирует Python-примеры, выполняет локальные примеры во временной папке, сверяет заявленный stdout и запускает примеры pytest. Примеры сетевых запросов и команды установки не выполняются. Второй получает результаты Python и Git заново и сравнивает их с сохранёнными данными. Команды Git выполняются только во временных учебных репозиториях.

Для намеренного обновления эталонов:

```bash
python tools/build_demo_fixtures.py
```

Проверено при расширении: **107 Python-примеров компилируются, 90 выполняются, 20 pytest-проверок и 14 JavaScript-проверок проходят**. Все шесть моделей проверены в браузере, включая возврат и сброс, ошибки и пустые результаты. Проверены поиск по новым блокам, старые прямые ссылки, обновление страницы, клавиатура, мобильная панель и отсутствие горизонтального переполнения страницы.

## Источники и уточнения

Внизу каждого урока — ссылки на его исходные материалы Skypro, в отдельных темах — ссылки на официальные документы. Это переработанные мини-конспекты для повторения. Записи с наставником, домашние задания, аттестация и проект не включены.
