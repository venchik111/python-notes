# Python · заметки

Личный справочник: **14 занятий, 66 тем**, компактные правила, примеры и частые ошибки. Материалы подготовлены по открытым урокам Skypro; названия и номера сохранены. Подробные пояснения раскрываются по нажатию.

Сайт: **https://venchik111.github.io/python-notes/**

## Использование

- Выбери урок слева или введи термин в поиске. Клавиша `/` переводит фокус в поиск.
- Поиск учитывает код, пояснения, части слов и русские/английские термины. Регистр и различие `е/ё` не важны.
- Нажми результат, чтобы перейти к теме. Совпадения подсвечиваются, найденные пояснения раскрываются.
- Ссылку из адресной строки можно сохранить: она открывает конкретный урок/тему и работает после обновления страницы.
- На телефоне список открывается кнопкой «Уроки». Escape закрывает панель; Escape в поиске очищает запрос.

Сайт работает на HTML, CSS и JavaScript. Сервер приложения, аккаунт Skypro и ключи API для его работы не нужны. Материалы загружаются с того же сайта; внешние шрифты и CDN не используются.

## Локальный просмотр

Из корня проекта:

```bash
python -m http.server 8000 --directory docs
```

Открой http://localhost:8000. На macOS/Linux при необходимости используй `python3`. Открытие `index.html` через `file://` не подходит: браузер может заблокировать загрузку JSON.

## GitHub Pages

Публикация настроена в **Settings → Pages → Deploy from a branch → main → /docs**. Файл `docs/.nojekyll` отключает обработку Jekyll. После push в main GitHub повторно публикует страницу. Ресурсы имеют относительные адреса и работают под `/python-notes/`.

## Пополнение через чат

Попроси: «Обнови python-notes по новым открытым урокам Skypro». Для следующего обновления агенту нужен доступ к кабинету и репозиторию.

1. Сопоставить открытые учебные занятия с существующими идентификаторами `stream-lesson`.
2. Прочитать шпаргалку и конспект; у практик — условия учебных задач. Сохранить исходные материалы вне репозитория.
3. Объединить повторы, оформить короткие темы и проверить существенные ограничения/примеры.
4. Добавить или обновить записи в `docs/data/lessons.json`. Не менять ID старых уроков и тем: они используются в ссылках.
5. Обновить дату, проверить поиск/примеры, commit и push. При изменении числа тем обновить счётчики в README; интерфейс считает их автоматически.

Новые уроки добавляются по запросу; автоматического доступа к Skypro из опубликованного сайта нет.

## Формат данных

`version: 1`, `updatedAt: YYYY-MM-DD`, список `modules`, список `lessons` в учебном порядке.

Урок: `id`, `moduleId`, `number`, `title`, `kind` (`lesson`/`practice`), `summary`, `sources`, `topics`. Необязательный `setup` содержит общие данные для примеров.

Тема: стабильный `id`, `title`, `when`, `rule`, `code`, `language`, `error`, `details` (пояснения), `terms` (синонимы для поиска), `references` (проверочные источники). Поле `check` задаёт проверку примера: `compile`, `run` или `pytest`; непитоновские примеры не выполняются. Текст выводится безопасно как текст, а не как HTML.

## Проверки

Для поиска и целостности данных нужен Node.js; npm-пакеты не требуются:

```bash
npm test
```

Для проверки примеров установи `pytest`, `pandas`, `requests` в отдельное окружение и запусти:

```bash
python tests/check_examples.py
```

Проверка компилирует все Python-примеры, выполняет локальные демонстрации во временной папке и запускает примеры тестов. Примеры запросов в интернет и команды Git/установки она не выполняет.

## Источники и уточнения

Внизу каждого урока — ссылки на его исходные материалы Skypro, в отдельных темах — ссылки на официальные документы. Это переработанные памятки для повторения, а не полные копии конспектов.

Исправлены, в частности: запуск тела генератора при первом `next()`, абсолютные компоненты `os.path.join`, смысл режимов `git reset`, fast-forward merge, перенос `poetry shell` в плагин и рекомендации PEP 8 о длине строки.
